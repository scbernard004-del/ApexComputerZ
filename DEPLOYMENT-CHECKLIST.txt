1. EXTRACT AND TEST
[ ] Extract the ZIP and open the apex-computers folder.
[ ] Double-click index.html and test the website.

2. CREATE GITHUB REPOSITORY
[ ] Open https://github.com/new
[ ] Repository name: apex-computers
[ ] Keep Add README, .gitignore and License unchecked.
[ ] Create the empty repository.

3. UPLOAD FIVE BATCHES
[ ] Batch 1: loose website files plus api, assets, data and lib.
[ ] Batch 2: media-01 only — 89 files.
[ ] Batch 3: media-02 only — 99 files.
[ ] Batch 4: media-03 only — 89 files.

[ ] Framework Preset: Other
[ ] Root Directory: default
[ ] Build Command: empty
[ ] Output Directory: empty/default
[ ] Click Deploy.
